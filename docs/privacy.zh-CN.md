# 隐私说明

Shelly Hermes Agent 是本地运行的开发工具核心。默认不会由本仓库代码主动收集遥测或上传工作区；但用户配置的模型服务、插件和命令可能处理并传输提示词、代码、文件片段、工具结果及诊断信息，其规则受对应服务提供方约束。

## 数据与控制
- 本地配置、日志、检查点和记忆可能包含敏感代码；用户负责访问控制、备份与删除。
- API key 仅应置于未提交的 `.env` 或系统密钥存储，不得写入提示词、日志或问题报告。
- 使用远程模型前应确认数据地域、保留、训练使用和删除政策；敏感项目可禁用相关插件或网络能力。
- 故障报告须脱敏；维护者不会要求提供私钥或完整 `.env`。

卸载时删除程序目录；如需清除数据，还应删除用户自行配置的工作区、`.shelly`、日志和凭据，并在模型服务端撤销 token。该说明不替代部署组织的隐私评估。
