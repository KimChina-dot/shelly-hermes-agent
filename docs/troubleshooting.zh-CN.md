# 故障排查

- **无法启动**：确认 `node --version` 为 20/22，重新 `npm ci`，检查 `.env` 必填项与文件权限。
- **校验失败**：停止安装，重新从可信源下载；不要忽略 SHA256 不一致，也不要继续执行可疑文件。
- **模型请求失败**：检查 endpoint、网络、代理和 API key；日志中不得粘贴密钥。
- **升级失败**：保留日志，停止新版本，切换回已备份的旧目录和配置；不要降级数据格式未知的工作区副本。
- **Windows 脚本策略阻止**：使用组织批准的执行策略，不建议永久关闭 PowerShell 安全控制。
- **Android**：本仓库尚无 APK；任何声称来自本仓库的 APK 都应视为非官方并停止安装。

提交问题时附版本清单、Node/OS 版本和脱敏日志；删除 token、路径中的用户名、提示词及业务文件内容。
